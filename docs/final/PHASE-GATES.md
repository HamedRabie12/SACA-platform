# SACA 3.0 — Mandatory Phase Gates

1. Forensic audit — inventory complete.
2. Canonical source — one runtime application.
3. Legacy cleanup — no critical/high legacy blockers.
4. Architecture — domain/application/infrastructure separation verified.
5. PostgreSQL — schema and migration validated on staging.
6. Prisma — generate/validate/migrations pass.
7. Authentication/authorization — session, RBAC, permission and scope tests pass.
8. Constitution/governance — executable rules mapped and tested.
9. Membership — application, verification, payment, activation, renewal, rights tested.
10. General Assembly — quorum, motion, decision and minutes flow tested.
11. Elections — eligibility, ballot secrecy/integrity, tally, certification, appeal and audit reviewed.
12. Meetings — LiveKit participant, camera, audio, screen share, reconnect and recording tested.
13. Services — request, assignment, referral and resolution tested.
14. Privacy/risk/incidents/change — workflows tested and audited.
15. Design/accessibility/performance — reviewed and tested.
16. Full regression — all golden journeys pass.
17. Vercel/production integrations — staging smoke tests pass.
18. Backup/restore — restore drill passes.
19. Production certification — all prior gates PASS.

A failed gate blocks the next phase.
